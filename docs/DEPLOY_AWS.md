# AWS EC2 배포 가이드 (t4g.small / Ubuntu 24.04 / ARM)

본 문서는 `pd-voice-diagnosis` (Streamlit) 을 AWS EC2 t4g.small 인스턴스에
상시 구동 상태로 배포하는 표준 절차입니다. Streamlit Cloud 의 sleep 모드
(7일 비활성 시 잠드) 문제를 완전히 해소합니다.

> Voice Lab Hub 의 다른 모듈(Next.js)도 동일 인스턴스에 올릴 수 있습니다.
> 이 경우 t4g.medium (RAM 4GB) 으로 한 단계 올릴 것을 권장합니다.

---

## 0. 예상 비용

| 항목 | 월관 예상 |
|---|---|
| **EC2 t4g.small** (2 vCPU ARM, 2GB RAM) | 약 $13 / 월 (온디맨드, 서울 리전) |
| **EBS gp3 30GB** | 약 $2.4 / 월 |
| **도메인** (선택) | Route53 hosted zone $0.5 / 월 |
| **데이터 전송** | 1GB/일 미만이면 무시 가능 |
| **Total** | **≈ $16 / 월** |

일반 수업·임상 트래픽 수준에서는 충분합니다. **Reserved Instance (1년 알)** 로\n전환하면 EC2 요금이 약 40% 절감됩니다.\n\n---\n\n## 1. AWS 콘솔 설정 (15분)\n\n### 1.1 EC2 인스턴스 생성\n\n1. EC2 콘솔 → **Launch Instance**\n2. 설정:\n   - Name: `voice-lab-prod`\n   - AMI: **Ubuntu Server 24.04 LTS (ARM64)** (Free tier eligible 가능)\n   - Instance type: **t4g.small** (ARM Graviton)\n   - Key pair: 새 RSA 키 페어 생성 (`voice-lab-key.pem` 저장)\n   - Network: Default VPC, **Auto-assign public IP: Enable**\n   - Storage: 30 GiB gp3 (기본 8GiB 는 부족)\n   - Tags: `Project=VoiceLab`\n\n### 1.2 보안 그룹 (Security Group)\n\n`voice-lab-sg` 를 다음 규칙으로 생성:\n\n| Type | Port | Source | 용도 |\n|---|---|---|---|\n| SSH | 22 | **내 IP 만** | 원격 관리 |\n| HTTP | 80 | 0.0.0.0/0 | Let's Encrypt + 임시 접속 |\n| HTTPS | 443 | 0.0.0.0/0 | 운영 접속 |\n\n⚠️ Streamlit 기본 포트 8501 은 **공개하지 않습니다**. nginx 가 앞에서\n프록시합니다.\n\n### 1.3 엘라스틱 IP (선택, 권장)\n\nEC2 인스턴스를 재시작해도 IP 가 유지되도록 Elastic IP 할당. 월관\n$3.6 추가.\n\n---\n\n## 2. 서버 초기 설정 (20분)\n\nSSH 접속:\n\n```bash\nchmod 400 ~/voice-lab-key.pem\nssh -i ~/voice-lab-key.pem ubuntu@<EC2_PUBLIC_IP>\n```\n\n### 2.1 시스템 패키지\n\n```bash\nsudo apt update && sudo apt upgrade -y\nsudo apt install -y \\\n  python3 python3-pip python3-venv \\\n  nginx git ufw \\\n  fonts-nanum fonts-nanum-coding \\\n  praat ffmpeg libsndfile1 \\\n  certbot python3-certbot-nginx \\\n  build-essential\n```\n\n> `fonts-nanum` 은 matplotlib 한글 라벨 극해 이슈 (CODE_REVIEW.md Minor 항목)\n> 해결용. `praat` 는 parselmouth 가 있으면 아주 필수는 아니지만 디버깅\n> 용으로 있으면 편하고, `ffmpeg`·`libsndfile1` 은 WAV 이외 포맷 입력\n> 호환을 위해 필요합니다.\n\n### 2.2 프로젝트 디렉터리 및 사용자 권한\n\n```bash\nsudo mkdir -p /opt/voice-lab\nsudo chown ubuntu:ubuntu /opt/voice-lab\ncd /opt/voice-lab\ngit clone https://github.com/ondam0047/pd-voice-diagnosis.git .\ngit checkout claude/voice-lab-hub-PIvNn   # 확정 후 main 으로\n```\n\n### 2.3 파이썬 가상환경 + 의존성\n\n```bash\ncd /opt/voice-lab\npython3 -m venv .venv\nsource .venv/bin/activate\npip install --upgrade pip wheel\npip install -r requirements.txt\npip install -r requirements_ml.txt\n```\n\n⚠️ ARM 아키텍처이므로 `parselmouth` 새치 wheel 이 불러와지는지 확인:\n```bash\npython -c \"import parselmouth; print(parselmouth.PRAAT_VERSION)\"\n```\n에러가 나면 소스 빌드가 일어나는데 (gcc/cmake 필요), `build-essential` 은 이미\n설치했으므로 그대로 성공합니다 (5–10분 소요).\n\n### 2.4 secrets 설정\n\nStreamlit 이 `st.secrets` 로 읽는 GCP 서비스 계정 / SMTP 정보를 올립니다:\n\n```bash\nmkdir -p /opt/voice-lab/.streamlit\nnano /opt/voice-lab/.streamlit/secrets.toml\n```\n\n```toml\n[gcp_service_account]\ntype = \"service_account\"\nproject_id = \"...\"\nprivate_key_id = \"...\"\nprivate_key = \"\"\"-----BEGIN PRIVATE KEY-----\\n...\\n-----END PRIVATE KEY-----\\n\"\"\"\nclient_email = \"...\"\nclient_id = \"...\"\n# ... 나머지 필드\n\n[gcp_info]\nsheet_name = \"PD_Voice_Results\"\n\n[smtp]\nsender = \"voice-lab@daelim.ac.kr\"\nsender_password = \"<app-password>\"   # Gmail 앱 비밀번호\nreceiver = \"...\"\n```\n\n권한 제한:\n```bash\nchmod 600 /opt/voice-lab/.streamlit/secrets.toml\n```\n\n---\n\n## 3. systemd 서비스 등록 (10분)\n\nStreamlit 을 백그라운드 상시 서비스로 돌립니다 (sleep 없음).\n\n### 3.1 서비스 파일\n\n```bash\nsudo nano /etc/systemd/system/voice-lab.service\n```\n\n```ini\n[Unit]\nDescription=Voice Lab Streamlit App\nAfter=network.target\n\n[Service]\nType=simple\nUser=ubuntu\nGroup=ubuntu\nWorkingDirectory=/opt/voice-lab\nEnvironment=\"PATH=/opt/voice-lab/.venv/bin\"\nEnvironment=\"PYTHONUNBUFFERED=1\"\nExecStart=/opt/voice-lab/.venv/bin/streamlit run app.py \\\n  --server.port=8501 \\\n  --server.address=127.0.0.1 \\\n  --server.headless=true \\\n  --browser.gatherUsageStats=false \\\n  --server.maxUploadSize=50\nRestart=always\nRestartSec=10\n# 많이 쓰는 상태에서 메모리 누수 방지\nMemoryMax=1500M\n\n[Install]\nWantedBy=multi-user.target\n```\n\n### 3.2 시작 및 자동실행 등록\n\n```bash\nsudo systemctl daemon-reload\nsudo systemctl enable voice-lab\nsudo systemctl start voice-lab\nsudo systemctl status voice-lab\n```\n\n로그 확인 (실시간):\n```bash\nsudo journalctl -u voice-lab -f\n```\n\n---\n\n## 4. nginx 리버스 프록시 + HTTPS (20분)\n\n### 4.1 도메인 설정\n\n도메인(예: `voicelab.daelim.ac.kr`) 의 A 레코드를 EC2 Elastic IP 로 설정.\n전파에 몇 분에서 몇 시간 소요.\n\n### 4.2 nginx 설정\n\n```bash\nsudo nano /etc/nginx/sites-available/voice-lab\n```\n\n```nginx\nserver {\n    listen 80;\n    server_name voicelab.daelim.ac.kr;\n\n    # 업로드 파일 크기 제한 (음성 WAV 대응)\n    client_max_body_size 100M;\n\n    location / {\n        proxy_pass http://127.0.0.1:8501;\n        proxy_http_version 1.1;\n        proxy_set_header Host $host;\n        proxy_set_header X-Real-IP $remote_addr;\n        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;\n        proxy_set_header X-Forwarded-Proto $scheme;\n\n        # Streamlit websocket\n        proxy_set_header Upgrade $http_upgrade;\n        proxy_set_header Connection \"upgrade\";\n        proxy_read_timeout 86400;\n        proxy_send_timeout 86400;\n    }\n\n    # Streamlit 정적 경로\n    location ~ ^/static {\n        proxy_pass http://127.0.0.1:8501;\n    }\n    location ~ ^/healthz {\n        proxy_pass http://127.0.0.1:8501/healthz;\n        access_log off;\n    }\n}\n```\n\n활성화:\n```bash\nsudo ln -s /etc/nginx/sites-available/voice-lab /etc/nginx/sites-enabled/\nsudo rm /etc/nginx/sites-enabled/default\nsudo nginx -t\nsudo systemctl restart nginx\n```\n\n### 4.3 Let's Encrypt HTTPS\n\n```bash\nsudo certbot --nginx -d voicelab.daelim.ac.kr\n# 이메일 입력, 약관 동의, HTTP → HTTPS 자동 리다이렉트 선택\n```\n\n인증서 자동 갱신은 certbot 이 systemd timer 로 설치해 줍니다. 확인:\n```bash\nsudo systemctl status certbot.timer\n```\n\n---\n\n## 5. 방화벽\n\n서버 내 ufw 도 구성:\n\n```bash\nsudo ufw allow ssh\nsudo ufw allow 'Nginx Full'\nsudo ufw enable\nsudo ufw status\n```\n\n이제 `https://voicelab.daelim.ac.kr` 접속 시 Streamlit 앱이 명시적으로\n뜨게 됩니다.\n\n---\n\n## 6. GitHub Actions 로 자동 배포 (선택, 30분)\n\n`main` 브랜치에 push 될 때마다 자동 재배포.\n\n### 6.1 EC2 에 deploy 사용자 + SSH 키\n\n```bash\n# EC2 안에서\nsudo adduser --disabled-password --gecos \"\" deploy\nsudo usermod -aG sudo deploy\nsudo mkdir -p /home/deploy/.ssh\n\n# 명령만 수행하도록 sudo 제한\nsudo nano /etc/sudoers.d/deploy\n```\n\n```\ndeploy ALL=(root) NOPASSWD: /bin/systemctl restart voice-lab\ndeploy ALL=(ubuntu) NOPASSWD: ALL\n```\n\n로컬에서 새 SSH 키 생성 후 EC2 의 deploy 사용자에 등록:\n```bash\nssh-keygen -t ed25519 -f deploy_key -N \"\"\n# deploy_key.pub 내용을 EC2 의 /home/deploy/.ssh/authorized_keys 에 추가\n```\n\n### 6.2 GitHub Secrets\n\n레포 Settings → Secrets and variables → Actions:\n- `EC2_HOST` = `voicelab.daelim.ac.kr` (또는 Elastic IP)\n- `EC2_USER` = `deploy`\n- `EC2_SSH_KEY` = `deploy_key` (private key 전체 내용)\n\n### 6.3 워크플로우 파일\n\n`.github/workflows/deploy.yml`:\n\n```yaml\nname: Deploy to EC2\n\non:\n  push:\n    branches: [main]\n\njobs:\n  deploy:\n    runs-on: ubuntu-latest\n    steps:\n      - name: SSH and deploy\n        uses: appleboy/ssh-action@v1\n        with:\n          host: ${{ secrets.EC2_HOST }}\n          username: ${{ secrets.EC2_USER }}\n          key: ${{ secrets.EC2_SSH_KEY }}\n          script: |\n            sudo -u ubuntu bash -c '\n              cd /opt/voice-lab\n              git fetch origin main\n              git reset --hard origin/main\n              source .venv/bin/activate\n              pip install -r requirements.txt -r requirements_ml.txt\n            '\n            sudo systemctl restart voice-lab\n```\n\n몇 분 안에 자동 재시작. 장애 시 Streamlit 이 10초 안에 다시 올라옵니다.\n\n---\n\n## 7. 운영 체크리스트\n\n- [ ] **백업**: `pd_tool.db` (sqlite) 와 `.streamlit/secrets.toml` 을\n  `/var/backups/voice-lab-$(date +%F).tar.gz` 로 매일 cron 백업.\n  S3 으로 올릴 수도 있음 (`s3 sync` + IAM 역할).\n- [ ] **모니터링**: CloudWatch 기본 지표 (CPU, 네트워크, 디스크) 무료.\n  알람은 SNS → 이메일 설정.\n- [ ] **로그 로테이션**: `/etc/logrotate.d/voice-lab` 추가 권장\n  (Streamlit 는 stdout 만 쓰므로 journalctl 이 관리).\n- [ ] **보안 업데이트**: `unattended-upgrades` 패키지로 자동 보안 패치 활성화.\n- [ ] **DB 경로 수정**: 현재 `app.py` 는 CWD 에 `pd_tool.db` 생성 →\n  `/opt/voice-lab/data/pd_tool.db` 경로로 고정 권장 (CODE_REVIEW.md Minor).\n- [ ] **도메인 갱신**: `certbot renew --dry-run` 으로 자동 갱신 검증.\n\n---\n\n## 8. Voice Lab Hub (Next.js) 동일 서버 배포\n\nNext.js 도 함께 올릴 경우:\n\n```bash\n# Node.js LTS (ARM 괴장)\ncurl -fsSL https://deb.nodesource.com/setup_22.x | sudo bash -\nsudo apt install -y nodejs\n\n# 프로젝트 디렉터리\nsudo mkdir -p /opt/voice-lab-hub\nsudo chown ubuntu:ubuntu /opt/voice-lab-hub\ncd /opt/voice-lab-hub\ngit clone https://github.com/ondam0047/pd-pace-trainer.git .\nnpm ci\nnpm run build\n```\n\nsystemd 서비스 (`/etc/systemd/system/voice-lab-hub.service`):\n```ini\n[Unit]\nDescription=Voice Lab Hub (Next.js)\nAfter=network.target\n\n[Service]\nType=simple\nUser=ubuntu\nWorkingDirectory=/opt/voice-lab-hub\nEnvironment=\"NODE_ENV=production\"\nEnvironment=\"PORT=3000\"\nExecStart=/usr/bin/npm start\nRestart=always\nRestartSec=10\n\n[Install]\nWantedBy=multi-user.target\n```\n\nnginx 에 서브블록 추가:\n```nginx\nserver {\n    listen 443 ssl http2;\n    server_name voicelab.daelim.ac.kr;\n    # ... ssl_certificate 설정\n\n    # Voice Lab Hub (Next.js) - 루트\n    location / {\n        proxy_pass http://127.0.0.1:3000;\n        # ... proxy headers 동일\n    }\n\n    # PD Voice Diagnosis (Streamlit) - /diagnosis 서브패스\n    location /diagnosis/ {\n        proxy_pass http://127.0.0.1:8501/;\n        # ... websocket 설정 계속\n    }\n}\n```\n\n이렇게 하면 `voicelab.daelim.ac.kr/diagnosis` 에서 바로 Streamlit 앱이\n뜨고, 교수님이 Voice Lab Hub 의 \"PD Voice Diagnosis\" 버튼에 이 경로를\n연결하시면 됩니다.\n\n---\n\n## 9. 트러블슈팅\n\n**Streamlit 이 안 떨 때**:\n```bash\nsudo journalctl -u voice-lab -n 100\n```\n가장 흔한 원인: secrets.toml 파싱 오류 (multi-line private key 의 `\\n`\n처리). `python -c \"import toml; toml.load('.streamlit/secrets.toml')\"` 로 검증.\n\n**메모리 에러 / OOM kill**:\nt4g.small 는 RAM 2GB. parselmouth 로 큰 WAV (수십 MB) 를 동시에 여러 번\n돌리면 근접. 스왈 2GB 설정:\n```bash\nsudo fallocate -l 2G /swapfile\nsudo chmod 600 /swapfile\nsudo mkswap /swapfile\nsudo swapon /swapfile\necho '/swapfile none swap sw 0 0' | sudo tee -a /etc/fstab\n```\n\n**ARM wheel 부재**:\n일부 Python 패키지는 ARM64 사전제작 wheel 이 없어 소스 빌드 필요.\n이미 `build-essential` 을 설치했으므로 대부분 해결되지만, 메모리 제약으로\n`pip install` 이 OOM 되면 `pip install --no-cache-dir` 또는 일시적으로\nt4g.medium 으로 upgrade 후 wheel 을 cache 해서 다시 downgrade.\n\n**Websocket 연결 끊김**:\nnginx 기본 `proxy_read_timeout=60s` 는 Streamlit 에 충분하지 않음. 위\n설정의 `86400` (하루) 으로 해결됨.\n\n---\n\n## 10. 다음 단계\n\n배포한 뒤 Voice Lab Hub `app/diagnosis/page.tsx` 을 다음과 같이 업데이트:\n\n```tsx\n// app/diagnosis/page.tsx 이 하는 일:\n//   1. 일정 시간 (예: 1일) 이 지난 후 자동으로\n//      `<iframe src=\"/diagnosis/\" />` 을 렌더링\n//   2. 또는 단순히 \"연결\" 버튼 → window.open(\"/diagnosis/\")\n```\n\n현재는 placeholder 이므로, EC2 배포 후에 Hub PR 을 올려 연결하시면\n됩니다.\n
